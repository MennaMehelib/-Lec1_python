# Python Data Types - Assignment

This repository contains solutions to practice questions on Python data types.

## Topics Covered

- Lists
- Sets
- Tuples
- Dictionaries

## Exercises

The assignment includes:

1. List operations
   - Append elements
   - Replace elements
   - Access items
   - Insert and remove items

2. Set operations
   - Add elements
   - Remove elements
   - Membership checking
   - Duplicate values

3. Tuple operations
   - Access elements
   - Membership checking
   - Tuple immutability

4. Dictionary operations
   - Access values
   - Update values
   - Add and remove key-value pairs

## Technologies Used

- Python 3
